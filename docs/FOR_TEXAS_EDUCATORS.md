# Commonstar Learning OS: for Texas educators and technology teams

**A public technical specification for a learning computer that keeps continuity with the learner.**

Commonstar is an independent open source project initiated by Hayden Lindley. Its aim is practical: give a learner a useful tutor, an organized library and an understandable record of work, while keeping authoritative personal memory on the learner's device.

## What a learner should be able to do

Open yesterday's goal, find the passage they were studying, ask for an explanation, try a new problem, and see what the software recorded. Continue without an internet connection. Correct a mistaken remembered fact. Keep the record when the model changes. Recover it when a laptop is lost or replaced.

Teachers should be able to select reviewed objectives and materials, distinguish assisted practice from independent work, and inspect explicitly shared evidence. The product is designed to support teaching and independent learning; it does not claim the authority to replace teachers or assign consequential educational placement.

## What is different about the design

The laptop contains both the learning record and a local model. A larger model on an approved workstation can help with difficult work. An optional cloud service is a separate, visible choice. The local application controls identity, retrieval, permissions and every saved change.

The learner can inspect sources and memory. A model's suggested interpretation is not automatically an established fact. The software does not need a provider's permanent hosted memory database. One chosen backup destination holds encrypted snapshots with a tested recovery path.

School deployment policy must address custody, retention, accessibility, approved destinations, content review and support. Local storage does not by itself establish legal compliance. A shared teacher report creates an additional authorized copy and is described that way.

## What exists now

Specification v1.0 includes the distro architecture, selected model packages, local memory and provider contracts, synthetic validation fixtures, and installation/release requirements. The repository's current status distinguishes specification checks from an implemented app, bootable image, device testing and educational evaluation.

The first intended real-data test is the originator's adult learning workflow on a laptop and Ubuntu workstation. The first proposed school learning unit concerns ordinary Grade 8 proportional and nonproportional linear relationships, with standards mappings and material reviewed by educators before use. The system's subject range is designed to expand through reviewed content packs.

## Contributions that would make the next stage useful

- Educators can review lesson accuracy, hint progression, reading level, source use and what counts as independent evidence.
- Accessibility specialists can evaluate actual keyboard, screen reader, mathematics and bilingual workflows.
- District technology teams can evaluate device policies, recovery custody, approved computation destinations and operational support.
- Researchers can help design independent and delayed assessments that distinguish better assisted answers from durable learning.
- Developers can implement and verify the complete local learning journey against the public contracts.

Use synthetic examples in public discussions. Student records and personal test vaults do not belong in GitHub issues or pull requests.
